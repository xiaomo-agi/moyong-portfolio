项目 · 工作方式

我不是在「用 AI」，是管着一支 Agent 队伍

13 个 Hermes Agent，每个管一个领域、各自干净上下文；中间靠飞书当消息桥，人只需要在手机上发指令和批结果——我只做决策，不做搬运。

13 个 Hermes Agent飞书 消息桥手机 随时调度0 独立产品

它解决什么

一个会话里塞太多任务，上下文会被污染：旧的结论影响新的判断，不同任务的产出混在一起没法追溯。所以我拆成了 13 个 Hermes Agent，各管一个领域，互不干扰。资料整理、资讯汇总、素材剪辑这几条流水线全跑在这套工作台上（看流水线清单 →）。

怎么跑起来的

  • 每个 Agent 一条独立会话，各管一个领域，互不干扰
  • 飞书做消息桥：文本、图片、文件、审批流都在飞书里过
  • 手机端当控制台：发起任务、看进度、批结果
  • 日常任务全部迁上去，形成肌肉记忆

我的做法

  • 按任务拆会话，保证上下文干净
  • 选一个 IM 当桥接层，让人和 Agent 用同一个界面
  • 把审批也放进消息流，人只做决策不做搬运
  • 日常任务全部迁上去，形成肌肉记忆
