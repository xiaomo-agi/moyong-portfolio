每天都要人工做一遍的活，我交给了 Agent

公司里总有一些活：每天要读一遍、每周要抄一遍、每次都要手工做一遍。它们吃掉的不是难度，是人的注意力。我把这类活拆成 SOP、交给 Agent 跑、再人工验收。

6 条流水线32 条/天 可用片十几个 Hermes Agent人工 验收才投产

六条流水线，都是真在跑的

  • 资料整理：成堆的岗位和客户资料要人工归档打标 → 自动入库、自动打标、状态自动回写
  • 资讯汇总：每天要手工读一遍的几个来源 → 定时抓取 + AI 提炼成一张卡，推到手机
  • 素材剪辑：一批素材排队等人剪 → 音轨识别 + 画面评判，单日最高 32 条可用片
  • 资料检索：资料散在各处，问谁都要翻半天 → 入库切分 + 语义检索，答案带出处可回溯
  • 内容生产：直播和口播的复盘靠人记 → 逐字稿分析 + 话术蒸馏 + 混剪流水线
  • 经验沉淀：能带人的经验只在少数人脑子里 → 写成 Skill，新人直接调用

每条流水线的细节

  • 素材剪辑：ASMR 自动剪辑方案 →
  • 资料检索：知识库管线与语义检索 →
  • 资讯汇总：每日自动汇总推送 →

我的做法

  • 先量：哪一步最吃人力，量化了再动手，不凭感觉
  • 拆 SOP：写成别人能照做的步骤，AI 才跑得稳
  • 跑：用 Claude Code 和 Codex 建 Skill 或工作流，按步骤执行而不是靠一次次的提示词
  • 验：人工验收卡口，我判断的是能不能用，不是看起来对不对

怎么保证它不出错

  • 按「70-80% 可用即投产」控制工程投入，不追求全自动
  • 发布、对外动作仍保留人工确认
  • 每条流水线都能单独重跑，出问题不拖累别的
