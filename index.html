我怎么干活

Method
01 · 拆

找出最耗人的那一条线

先看流程哪一步最吃人力，写成能交给别人照做的步骤。不梳理清楚就不动手。

02 · 跑

交给 Agent 按 SOP 执行

用 Claude Code 和 Codex 建 Skill 或工作流，让它按步骤跑，而不是靠一次次的提示词。

03 · 验

人工验收才投产

AI 产出必须过一遍人工验收。我判断的是能不能用，不是看起来对不对。
