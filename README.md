# moyong-portfolio

小 mo 的个人作品集（求职用）· 静态站 · GitHub Pages

## 安全约定（改动前先读）
- 本仓库**只包含** index.html、projects/ 下的作品页与 img/ 下的图片，**不得**加入任何 .env、凭证、脚本依赖
- **零第三方脚本、零 CDN、零表单、零统计**：页面不发起任何外部请求，无供应链风险、无注入面
- 动效全部为原生 CSS（scroll-driven animations），不引入任何 JS 库
- 图片一律脱敏后上传：**不含简历、投递记录、公司名、私人数据**；简历只随邮件发送，不上站
- 邮箱点击复制的脚本是页面内联的 8 行原生 JS，不做任何网络请求
